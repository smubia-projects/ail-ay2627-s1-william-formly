✨ Formly

Fill in any application form in seconds

Formly is a Chrome extension that reads a form, answers every question from your profile and resume, writes the long answers too, and learns new facts when you submit. This playground runs the same code on a sample form.

  1. Add a profile. or write your own (stored in this browser only).
  2. Press ✨ Fill with Formly (bottom right). Blue boxes were filled; orange ones are left for you.
  3. Type a new answer and press Submit. Formly saves it to your profile for the next form.

On a real site, install the extension: download it from GitHub and load the client folder in chrome://extensions.
